Qué incluir dentro de services

    **Peticiones HTTP externas**: Funciones que consumen APIs de terceros o microservicios (ej. stripeService.js, weatherApi.js).

    **Lógica de negocio pura**: Reglas específicas de tu aplicación que no pertenecen al framework (ej. cálculo de impuestos, procesamiento de carritos de compras, algoritmos de recomendación).

    **Integraciones del sistema**: Envolturas para herramientas de mensajería, envío de correos o sistemas de almacenamiento (ej. emailService.js, s3StorageService.js).
